# usml_homework

This repository contains my submission for my Unsupervised Machine Learning course (`VEMISAM255N/2025/26/2`, [Moodle course page](https://moodle.uni-pannon.hu/course/view.php?id=29943)).

## Task description

> Translated from the original Hungarian.

Homework Assignment and Report: During the semester, a homework assignment must be completed on a freely chosen topic from the semester's material. The available topics are:

- solving a clustering task/problem;
- solving a problem related to an association task;
- developing a recommender system;
- any other topic that contains at least one of the three topics listed above as a dominant element.

The homework assignment must be prepared in a Jupyter notebook, and then the notebook (and, if necessary, the associated datasets) must be uploaded to the Moodle system by the given deadline. The use of AI tools is permitted while preparing the homework assignment.
